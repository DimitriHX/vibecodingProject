📘 Actividad Evaluada
Implementación de Aplicación Next.js mediante Vibe Coding: Flujo de Desarrollo Guiado por IA

El objetivo de esta actividad es construir una aplicación web funcional con Next.js utilizando el flujo de Vibe Coding, empleando herramientas de inteligencia artificial como asistentes principales de generación de código, estructura y diseño.

El estudiante deberá demostrar su capacidad para dirigir, validar e iterar sobre el código generado por IA, manteniendo control sobre la arquitectura del proyecto y produciendo un resultado final de calidad profesional.

📚 Caso de Estudio
Desarrollarás una aplicación web completa con Next.js desde cero utilizando la metodología de Vibe Coding, donde la inteligencia artificial actúa como copiloto de desarrollo.

El proyecto simula un escenario real de trabajo en el cual un desarrollador junior debe entregar una aplicación funcional en un tiempo limitado, apoyándose en herramientas de IA para acelerar el flujo de trabajo.

La aplicación deberá demostrar dominio del ciclo completo de Vibe Coding:

Concepción inicial del proyecto
Creación de prompts efectivos para generar código
Generación iterativa de componentes
Validación y revisión del código generado
Corrección de errores
Optimización del resultado final
Despliegue en producción
Este ejercicio refleja la realidad del mercado actual, donde los desarrolladores deben ser capaces de colaborar eficientemente con herramientas de IA para construir productos funcionales en menor tiempo sin perder control sobre la calidad del código.

La temática de la aplicación es libre y será definida por cada estudiante.

⚙️ Requisitos Técnicos
Framework y Versión
Utilizar Next.js 16 o superior con App Router.
Lenguaje
El proyecto debe desarrollarse utilizando TypeScript.
Herramienta de IA
El estudiante puede utilizar cualquier asistente de IA como copiloto de desarrollo:
GitHub Copilot
Cursor
ChatGPT
Claude
v0.dev
u otras herramientas equivalentes
Estilos
Se recomienda utilizar Tailwind CSS, aunque también se aceptan CSS Modules.
Funcionalidades mínimas de la aplicación
Mínimo 4 páginas o rutas distintas utilizando App Router.
Consumo de al menos una API externa o interna mediante:
Route Handlers
o servicios serverless como Supabase
Uso combinado de Server Components y Client Components.
Manejo de estados con hooks de React:
useState
useEffect
Diseño responsive adaptable a dispositivos móviles y escritorio.
Manejo básico de:
Estados de carga (loading UI)
Errores de ejecución (error UI)
Despliegue
La aplicación debe estar desplegada y accesible públicamente. Vercel es la plataforma recomendada.
Repositorio
El código debe alojarse en GitHub con historial de commits que evidencie el proceso iterativo de desarrollo.
Variables de Entorno
Las claves de API y configuraciones sensibles deben gestionarse mediante el archivo .env.local.
📦 Entregables
Repositorio público en GitHub que contenga:
Código fuente completo del proyecto Next.js.
Historial de commits con mensajes descriptivos.
Archivo .env.example con variables necesarias documentadas.
Archivo README.md con instrucciones de instalación, uso y enlace al despliegue.
Documento de proceso de Vibe Coding (Puede incluirse dentro del README o en un archivo llamado VIBE_CODING.md) que registre:
Los prompts principales utilizados
Las iteraciones realizadas con la IA
Las decisiones técnicas tomadas
Los desafíos encontrados y cómo fueron resueltos con apoyo de IA
URL pública de la aplicación funcionando en producción (Vercel u otra plataforma de despliegue).
